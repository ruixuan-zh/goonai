# goonai two-minute demo

This clip is designed to occupy **1:30–3:30** of the five-minute video. Record the browser only, at 100% zoom or slightly smaller if your capture area is below 1280 × 720. Use the default **Curated scenario** and **replay** mode so the result is deterministic and does not require AWS credentials.

## Recording script

| Clip time | Full-video time | On screen | Narration |

## Recording checklist

- Refresh the page before each take so it starts with the incoming alert and no open case.
- Keep the pointer still while speaking; move it only when directing attention or clicking.
- Do not open the evidence ledger or agent trace during the main take. They are useful for questions, but they interrupt the two-minute narrative.
- Do not click **Approve** in the main take. The visible approval gate is enough to demonstrate that human authority is preserved.
- Pause briefly after each click so the edit has a clean cut point.
- If the clip runs long, shorten the four-explanation narration before cutting the final update beat.
